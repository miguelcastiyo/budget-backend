## Invariant classification and future use

Financial-semantic rules move to the client domain engine because the backend cannot see protected plaintext. Data-integrity and security rules are often shared: the client preserves meaning while the backend enforces opaque ownership, revisions, tombstones, size, and authorization. Synchronization and operational rules remain backend-owned. High-priority invariants must each have deterministic Phase 0D fixtures before implementation begins.
